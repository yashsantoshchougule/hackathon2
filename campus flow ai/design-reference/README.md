This replacement Canva candidate was generated with CampusFlow naming throughout. The candidate has not been saved as a final editable Canva design. The implementation remains native React and CSS; no dashboard images are used as functional UI.

Visual decisions: a restrained lavender recommendation card, white cards on #F7F8FC, a 246px sidebar, task-first hierarchy, attendance progress bars with text statuses, and an entirely native React landing preview. On mobile the sidebar becomes a keyboard-trapped drawer and cards stack. Red, amber and green indicate risk states only.
